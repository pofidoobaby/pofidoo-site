# pofidoo baby - Web Sitesi

## Yerel geliştirme
npm install
npm run dev

## Canlıya alma (Vercel/Netlify)
1. Bu klasörü bir GitHub reposuna yükleyin
2. Vercel.com veya Netlify.com'da "New Project" ile bu repoyu bağlayın
3. Build ayarları otomatik algılanır (Vite projesi)
4. Deploy edin, size ücretsiz bir *.vercel.app veya *.netlify.app linki verilir
5. Kendi domaininizi (örn. pofidoobaby.com) "Domain Settings" kısmından bağlayabilirsiniz
